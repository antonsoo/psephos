# Allotment workshop design

A learner asks whether two named tickets will enter the service pool together.
The central object is a five-column board with four, six or eight full rows.
Clicking two tickets in the same letter column swaps them before a draw. Pair
selectors follow identities across those moves. A white/black cube decides a
whole row; the release lane is explicitly schematic, not reconstructed hardware.

Retain the existing Psephos palette and locally retained type. Tokens: mist
#edf4f3, chalk #fbfdfb, patina #153d39, green #26766c, plum #98394a, line #b6ccc4.
Literata carries Greek and the question; Source Sans 3 carries instructions and
numeric results. Avoid another column of decorative cards: make the board
itself the visual focus, with exact outcome strips after an intentional reveal.

```
Question: will these two serve together?
[ rows / white cubes ]             [ the two identities ]
[ A  B  C  D  E | cube / result ]   [ before-draw relation ]
[ ticket rows, swap in column   ]   [ reveal exact chances ]
[ release / undo / reset        ]   [ keep / compare       ]
[ every colour order, explicitly revealed                  ]
[ Greek + close English          | whole scanned page     ]
[ explanation / saved study / illustrated portable reading ]
```

The existing mist-and-patina scheme belongs to this project, so changing it to
claim novelty would weaken continuity. The distinctive element is the movable
row mechanism and outcome strips. All five columns fit on a phone; ticket
buttons have a 44px minimum target. Text and W/B labels duplicate colour states.
All placement, reading and outcome operations work with a keyboard.

The intellectual payoff must stay visible: with four rows and two white cubes,
two fixed same-row tickets are selected together in 3 of 6 colour orders.
Move one to another row: both individual chances stay 1/2 while joint selection
falls to 1/6. Neither describes independent per-person coin tosses. Before the
placement is fixed, different probability assumptions can give another answer.
