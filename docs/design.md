# A courtroom workbench

The learner is an English-speaking visitor who has never read Greek. Their job
is to cast the last ballot, understand which urn counts, and distinguish a
visible count from evidence about how it was made. A modern ten-person panel
makes the last-vote experiment legible; it is not an ancient jury size.

## Visual plan

Oxidized bronze suggests a cool green working surface, with the ballots themselves
in bronze. Keep the objects large enough to see the axle ends. Avoid the customary
cream-and-terracotta antiquity theme and a grid of lesson cards.

| Token       | Value   | Purpose                       |
| ----------- | ------- | ----------------------------- |
| Mist        | #edf4f3 | Page                          |
| Chalk       | #fbfdfb | Reading and controls          |
| Deep patina | #153d39 | Type and selected actions     |
| Verdigris   | #26766c | Focus and observation         |
| Bronze      | #896b3b | Ballots                       |
| Warning     | #98394a | Exposed grip or invalid count |

Literata gives the Greek and headline a readable scholarly voice. Source Sans 3
keeps instructions quiet. Both are retained locally with their font licenses.
Everything aligns to the left except the actual ballot ends and urns, whose
placement expresses the procedure. A single wide stage is the memorable element.

```text
name / premise                         read / keep / boundaries
Two ballots. One unseen vote.          source and experiment
+------------------------------------+---------------------+
| your pair / private choice          | issue -> cast       |
| two enlarged axle ends              | spectator's view    |
| bronze urn       wooden urn         | pin and compare     |
+------------------------------------+---------------------+
| count board                         | result / source     |
+------------------------------------+---------------------+
Greek / close English                 full printed witness
museum photograph                     what survives
explanation / citations               portable record
```

On a narrow screen the same reading order becomes one column. Buttons replace
dragging. Every change has a text equivalent. Only a chosen action changes the
view; the page has no automatic motion.

## Review before implementation

The initial idea of a decorative bronze museum hero would delay the learner's
first action. Use operative ballot drawings instead, then show the real objects
beside the source evidence below. Numbered marks belong only to the sequence of
actions, not to arbitrary content sections. The counting board uses shape as well
as color. A covered axle must have the same observer drawing whichever private
ballot was selected.

## Source boundary

The objects, grip, urn distinction and tie rule follow _Athenaion Politeia_
68.2–69.1. The training panel, pinning, simplified coupled deposit and deliberate
counting interventions are modern teaching tools. No case, historical verdict,
original vessel shape, finger anatomy, or perfect secrecy guarantee is invented.
The supplied Greek is checked against the complete retained 1920 printed pages.
